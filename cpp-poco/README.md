# POCO C++ flavor

## Requirements

Build [c-exprtk-adapter](../c-exprtk-adapter), [c-meval-adapter](../c-meval-adapter),  framework `build-framework.sh`, Google Test `../test/build-googletest.sh` first

## Build

### Wrapped cmake

```sh
./release.sh
```

### Pure make

```sh
make clean && make
```

###

## Run

```sh
./Release/calc
```
